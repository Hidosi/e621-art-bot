# e621 Telegram Art Bot

Бот для автоматической загрузки случайных изображений с e621.net по заданным тегам и отправки их в Telegram с рандомной подписью и тегами художников и персонажей.

---

## 🔥 Возможности

- 📥 Загрузка одного случайного арта с e621 с поддержкой параметров тегов  
- 🧦 Использование SOCKS5 прокси для запросов  
- 🖼 Автоматическое сжатие изображений перед отправкой  
- 💬 Отправка изображения в Telegram с рандомной подписью из отдельного файла `captions.txt`  
- 🎨 В подписи отображаются теги художников (`artist`) и персонажей (`character`)  
- ⏰ Планировщик запуска бота с настраиваемым интервалом (минуты/часы)  
- 🔄 Отслеживание уже отправлённых постов, чтобы не дублировать публикации (файл `sent_posts.json`)  
- 🌐 Веб-интерфейс на Streamlit для управления настройками и мониторинга работы бота

## 🚀 Установка

1. Клонировать репозиторий и перейти в папку с проектом:

```bash
git clone https://github.com/Hidosi/e621-art-bot.git
cd e621-art-bot
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Подготовить конфигурацию:

- Скопировать `config.example.yaml` в `config.yaml` и заполнить свои данные (API ключи, прокси, теги и т.д.)  
- Создать файл `captions.txt` с подписями (по одной на строку)  

4. Запустить веб-интерфейс:

```bash
streamlit run app.py
```

5. Для запуска бота без веб-интерфейса:

```bash
python bot.py
```

## 📦 Структура проекта

```
/project_root/
├── app.py                  # Веб-интерфейс на Streamlit
├── bot.py                  # Логика бота
├── config.example.yaml     # Пример конфигурации без секретов
├── config.yaml             # Конфигурация (создаётся пользователем)
├── captions.txt            # Файл с подписями для картинок (по одной на строку)
├── requirements.txt        # Зависимости проекта
├── e621_bot.log            # Лог файл (создаётся при работе)
├── sent_posts.json         # Файл с ID уже отправленных постов (создаётся при работе)
└── downloaded_images/      # Папка для сохранённых изображений, с подпапками по дате
```

## Важно

Для работы бота необходимы:

- Учётная запись и API ключ на e621.net  
- Telegram Bot Token и chat_id (для групповых чатов указывайте chat_id с префиксом `-100`)  
- При использовании прокси – корректные настройки в `config.yaml`  

Проект в активной разработке — предложения и багрепорты приветствуются!
